## About the game data here

The module ships the data it needs to run — class progressions, equipment and firearms tables, the
crit/fumble charts, the Fear and Madness tables. That content is **© David Baity / Reroll
Productions and is not licensed.** The MIT licence in `LICENSE.txt` covers the module code only and
grants nothing over the game content. See [LICENSE.txt](LICENSE.txt).

If Reroll Productions would like anything here changed or removed, open an issue and it will be
done.
